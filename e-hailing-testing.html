01 / PROJECT OVERVIEW

Understanding the application.

This project involved quality assurance testing of an e-hailing super application designed to connect drivers and customers through ride-related services and additional digital features.

Testing covered both driver-side and customer-side experiences across iOS, Android and web platforms. The focus was on validating functionality, exploring application behaviour, identifying defects and supporting software quality.

02 / TESTING APPROACH

04 / DEFECT INVESTIGATION

Real-world defect example.

BUG REPORT / BUG-001

Live captions persist across application modules.

Modules: Social Media Hub and Chats

Steps to reproduce:

1. Open the Social Media Hub.
2. Start a live session.
3. Enable captions.
4. Navigate to the Chats module.
5. Initiate a video call.
6. Observe the caption behaviour.

Expected result:

Captions should not unintentionally persist from the live session into a separate video call.

Actual result:

Captions continued displaying during the video call.

Testing focus:

Exploratory testing and cross-module functionality.

05 / DEFECT MANAGEMENT

Documentation and tracking.

ClickUp was used to record and track identified application defects. Screenshots were captured and attached to reports to provide supporting visual evidence of unexpected behaviour.

Defect reporting process

Issue identification → Reproduction → Screenshot evidence → ClickUp reporting → Tracking and follow-up.

06 / PROFESSIONAL TAKEAWAYS

What this project demonstrates.

It also highlights the importance of testing interactions between application modules rather than evaluating individual features in isolation.
